afterlimit
v0.1 · runs in your browser

Your AI hit its limit. Your work didn't.

When Claude or Codex runs out mid-task, afterlimit gets a proper handoff note out of the first agent and turns it into a pickup prompt for the next one. The new agent starts where the old one stopped, and you skip re-explaining the project.

Why a note beats the chat log

    

      
Most switchers pass along your code and the last message. The code shows what exists. It doesn't show why, and that's where the damage happens. The new agent retries a fix that already failed, or undoes a choice you made an hour ago for a reason it can't see.

      
So afterlimit asks the outgoing agent for the things that only live in its head: what was tried and failed, which decisions were made and why, and the single next step. Step 2 flags any of those that are missing, because every missing section is something you'll end up explaining by hand.

      
There's also a command-line version. Run npx afterlimit init in your project and both agents keep the note current while they work, so it's ready the moment a limit hits.
